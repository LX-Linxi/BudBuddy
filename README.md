## 📖 项目简介

**伴芽（BudBuddy）** 是一个面向 **0～6 岁宝宝家庭**的 AI 科学育儿陪伴平台。

项目希望通过：

* 🌱 科学育儿知识
* 📊 宝宝成长数据
* 🤖 AI 智能能力
* 👨‍👩‍👧 父母经验交流

为家庭提供覆盖 **成长指导、成长记录、辅食管理、AI 育儿问答和家庭成长管理**的一站式育儿服务。

伴芽不仅关注宝宝的成长，也关注父母在育儿过程中的学习、陪伴与成长。

### 产品愿景

> **让每一位父母，都拥有一位值得信赖的 AI 育儿伙伴。**

# 🎯 产品定位

伴芽希望解决父母在育儿过程中经常遇到的几个问题：

```text
不知道孩子现在应该关注什么
            ↓
       月龄成长指南
            ↓

            ↓
       成长记录 + 辅食助手

       AI 育儿助手
            ↓

```

最终形成：

```text

     ┌────────────┼────────────┐

     ↓            ↓            ↓
```

# ✨ 核心理念

### 🌱 陪伴成长

陪伴宝宝成长，也陪伴父母成长。

### 📚 科学育儿

基于可靠的育儿知识、公开指南和专业资料，为父母提供易于理解的成长信息。

### 🤖 AI 助手

利用大语言模型理解宝宝的成长数据和父母的问题，提供更加个性化的辅助建议。

### 🔒 尊重隐私

宝宝的成长数据属于家庭的重要隐私，产品设计过程中优先考虑数据安全、权限控制和最小化数据采集。

### 👨‍👩‍👧 共同成长

连接真实家庭，让育儿经验能够被分享、交流和沉淀。

帮助父母更加系统地管理宝宝辅食。

* 🥕 食物推荐
* 🔓 食物解锁
* 🚫 排敏记录
* 🍽️ 每日饮食记录
* 📊 饮食分析
* 🎯 个性化辅食建议

---

## 🤖 AI 育儿助手

基于大语言模型构建 AI 育儿助手。

规划能力包括：

* 💬 AI 育儿问答
* 🧠 成长情况分析
* 😴 睡眠分析
* 🥣 喂养建议
* 📊 成长数据分析
* 📅 每日育儿计划
* 🎯 个性化成长建议

例如：

```text
宝宝：8个月16天

最近：
- 睡眠记录正常
- 已解锁 38 种食物
- 最近新增辅食：牛油果

AI：

今天可以继续尝试新的蔬菜类食物，
同时保持已经适应食物的摄入。

今天可以重点关注：
① 爬行与扶站练习
② 白天规律小睡
③ 新食物单独观察
```

> AI 输出仅作为育儿信息辅助，不替代医生、营养师或其他专业人士的诊断和建议。

# 🏗️ 技术架构

伴芽采用**前后端分离 + AI 服务化 + 数据驱动**的架构思路。

```text
                    ┌─────────────────┐
                    │   微信小程序     │
                    │   BudBuddy      │
                    └────────┬────────┘
                             │
                         API / HTTPS
                             │
                    ┌────────▼────────┐
                    │   Backend API   │
                    │    FastAPI      │
                    └────────┬────────┘
                             │
              ┌──────────────┼──────────────┐
              │              │              │
              ▼              ▼              ▼
          MySQL           Redis        Object Storage
          数据库          缓存           成长照片
              │              │
              └──────┬───────┘
                     │
                     ▼
              ┌──────────────┐
              │ AI Service   │
              │              │
              │ LLM          │
              │ RAG          │
              │ Agent        │
              └──────────────┘
```

# 📝 Git Commit 规范

项目采用 **Conventional Commits**。

格式：

```text
<type>(<scope>): <description>
```

常用类型：

| Type       | 用途     |
| ---------- | ------ |
| `feat`     | 新功能    |
| `fix`      | Bug 修复 |
| `refactor` | 重构     |
| `style`    | 样式调整   |
| `docs`     | 文档     |
| `test`     | 测试     |
| `chore`    | 工程配置   |

示例：

```bash
git commit -m "feat(home): complete home page v1"

git commit -m "feat(guide): add monthly growth guide"

git commit -m "fix(home): resolve quick entry layout issue"

git commit -m "refactor(home): extract reusable components"

git commit -m "docs: update README"
```

# 🧩 开发原则

### 1. 产品优先

先解决真实育儿问题，再考虑技术实现。

### 2. 数据驱动

尽量避免将业务数据硬编码在页面中。

### 3. 组件化

重复 UI 抽象为可复用组件。

### 4. 模块化

页面、业务逻辑、API、数据模型保持清晰边界。

### 5. 可测试

核心业务逻辑需要具备可测试性。

### 6. 安全优先

涉及宝宝数据、家庭数据和照片时，采用最小权限原则。

### 7. AI 可解释

AI 建议需要尽可能说明依据，并明确 AI 能力边界。

# 💙 为什么做伴芽？

育儿没有标准答案。

每个宝宝都有自己的成长节奏，每位父母都会经历：

```text
焦虑
 ↓
困惑
 ↓
学习
 ↓
尝试
 ↓
记录
 ↓
成长
```

我们希望：

> **AI 不替代父母，而是成为父母身边可靠的助手。**

伴芽希望连接：

**科学知识 × 成长数据 × AI × 真实经验**

让技术真正服务于家庭，而不是增加父母的信息负担。
