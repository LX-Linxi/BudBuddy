# 📖 项目简介

**伴芽（BudBuddy）** 是一个面向 **0～6 岁宝宝家庭** 的 AI 科学育儿平台。

我们希望借助 AI、科学育儿知识和社区力量，为每个家庭提供覆盖 **成长指导、成长记录、智能问答、经验交流** 的一站式育儿解决方案。

伴芽不仅关注宝宝成长，更关注父母在育儿过程中的陪伴、学习与成长。

我们的愿景是：

> **让每一位父母，都拥有一位值得信赖的 AI 育儿伙伴。**

# 💙 为什么做伴芽？

育儿没有标准答案。

每个宝宝都有自己的成长节奏，每位父母都会经历焦虑、困惑和惊喜。

我们相信，AI 不应该替代父母，而应该成为父母可靠的助手。

**伴芽（BudBuddy）** 希望用技术连接科学育儿知识与真实育儿经验，为每个家庭提供长期、可信赖的陪伴。
